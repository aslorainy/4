# Libreta Almacén

Aplicación de inventario offline para Android.

## Funciones
- Productos: nombre, precio y stock.
- Entradas.
- Movimientos Varadero ↔ Matanzas.
- Ventas.
- Dinero recogido.
- Retirar productos por daño, rotura u otros motivos.
- Inventario actual.
- Resumen.
- Guardado local sin internet.

## APK
GitHub Actions genera un APK debug desde `.github/workflows/build-apk.yml`.
